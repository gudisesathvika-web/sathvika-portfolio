    sathvika-sketch.png

    public/portrait/sathvika-sketch.png

Recommended: a fine-art pencil sketch based on your own portrait
(natural facial features, subtle crosshatching), roughly square (1:1),
at least 800x800 px.

Until this file exists, the hero renders an elegant crosshatch "SG"
placeholder instead. A different stock photo is never used as a stand-in.

Supported alternatives: if you prefer a different extension, update
`assets.portrait.path` in src/data/content.ts to match.
